# Ledger Social

The phone app behind [@ledgerexplained](https://www.instagram.com/ledgerexplained/): Instagram stats, scheduling, batch reposts with credit, a comment manager, and a no-VPN app blocker (Focus).

## Install

Download the latest `LedgerSocial-x.y.z.apk` from [Releases](../../releases/latest) and open it on an Android phone (Android 11+).

## Updates

The app checks this repository's latest release and installs new versions from **Settings → App updates**.
